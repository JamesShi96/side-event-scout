# Side Event Scout

大会周边活动（Side Events）自动搜集与整理 Skill。给定一个大会名称（如 WAIC 2026、ICML 2026、NeurIPS 2026），自动完成：

**发现** → 搜索 Luma 日历 / 行业媒体盘点 / 聚合站 / 微信·小红书 / 定向主办方 等多路信息源
**整理** → 逐个打开活动页，按 ZP 固定 12 列格式录入
**去重** → 标题+日期主键，多平台重复发布合并
**评级** → S / A / B / C 四级（主办方质量 × 人群匹配 × 规模深度 × 信息可信度）
**输出** → 按日期排序的飞书表格（ZP 模板布局）

**核心边界：只收大会「场外」的非官方周边活动**（晚宴 / Mixer / Party / Coffee Chat / 闭门交流 / 招聘晚宴等），不收官方 keynote / tutorial / workshop / 展台活动。

## 安装（3 步，像装个软件一样简单）

**用 Claude Code 的：**

1. 下载本仓库（页面右上角绿色 `Code` 按钮 → `Download ZIP`，解压；会用 git 的直接 clone）
2. 把整个文件夹复制到 `~/.claude/skills/side-event-scout/`（Mac 上在终端执行：`cp -r 解压后的文件夹路径 ~/.claude/skills/side-event-scout`）
3. 重新打开 Claude Code，就装好了

**用 Codex 或其他 AI 编程工具的**：只需要 `portable/skill.md` 这一个文件，放进你工具的自定义指令/skill 目录即可（格式规范已内嵌，不依赖其他文件）。

## 用法

对 AI 说一句话即可：

> 帮我整理 WAIC 2026 的 Side Events

它会自动搜索、整理、评级，最后**问你要哪种交付形式**：

- **A. 直接生成飞书表格**（需要装好 lark-cli 飞书命令行工具并授权你的飞书账号；没装也没关系，AI 会带你弄，或者直接选 B）
- **B. 生成 CSV 表格文件**（什么都不用装；拿到文件后在飞书里"新建 → 导入"上传，或直接用 Excel 打开）

跑完返回：表格（链接或文件）+ 分级统计 + S/A 级活动点名 + 搜索覆盖说明。

💡 **最佳使用时机是大会开始前 1-2 周**：周边活动信息在大会结束后会快速下线（Luma 下沉、聚合站删列表），赛后再查能找到的会少很多。

## 试跑记录

| 大会 | 结果 | 验证 |
|------|------|------|
| ICML 2026（首尔，2026.7.6-11） | 77 个活动，S×12 / A×32 / B×28 / C×5 | 对照 ZP 人工表查全率约 65%，另挖出 28 个人工表没有的活动（含 General Catalyst 私宴、青源会闭门晚宴等 S 级） |
| WAIC 2026（上海，2026.7.17-20） | 29 个活动，S×7 / A×13 / B×4 / C×5 | 中文源为主力（WaytoAGI 聚合站 + 媒体盘点 + Wayback 存档回溯），Luma 仅贡献 3 个 |

样例产出见 `examples/`（markdown 中间产物；正式交付为飞书表格）。

## 已知盲区

- 纯邀请制、无公开页面的活动（私密邮件邀请类）自动化搜不到，需人脉情报补充
- 微信公众号原文普遍无法被搜索引擎命中，主要靠行业媒体转载/盘点文覆盖
- 聚合站在大会结束后常下线历史列表，需用 Wayback Machine 快照回溯（技巧已写入 skill）
